# Barakah Mart
একটি simple responsive e-commerce demo.

## চালানো
`index.html` ফাইলটি Chrome/Edge-এ খুলুন।

## বর্তমান ফিচার
- Product search
- Categories
- Add to cart
- Cart total
- Cash on Delivery / bKash / Nagad selection (demo)
- Responsive layout

## গুরুত্বপূর্ণ
bKash/Nagad-এর real payment নিতে merchant account ও server-side payment gateway integration প্রয়োজন। এই demo-তে কোনো আসল টাকা লেনদেন হয় না।
